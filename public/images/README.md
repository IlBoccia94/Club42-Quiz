# Immagini Club42 Quiz

Carica qui le immagini che vuoi usare nell'app: logo, mascotte, sfondi, illustrazioni dei round e altri asset grafici.

Percorso repository:

`public/images/`

Con Vite questi file vengono pubblicati insieme alla web app e possono essere richiamati dal frontend tramite `${import.meta.env.BASE_URL}images/nome-file.ext`.

## Convenzioni consigliate

- usa nomi semplici in minuscolo, ad esempio `logo-club42.png`, `balena-quiz.png`, `sfondo-classifica.jpg`;
- evita spazi e caratteri speciali nei nomi;
- per loghi e illustrazioni con trasparenza preferisci PNG o WebP;
- per fotografie preferisci WebP/JPG ottimizzati.

Non inserire in questa cartella file contenenti credenziali o dati riservati.
